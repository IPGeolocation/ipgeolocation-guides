# IPGeolocation.io OpenAPI specs

The OpenAPI specifications for the IPGeolocation.io APIs live in one repository: **[IPGeolocation/openapi](https://github.com/IPGeolocation/openapi)**. It is updated whenever the API changes.

This folder used to hold copies of those files. The copies fell out of date, so they were removed. Use the files below instead.

| API | OpenAPI 3.0 YAML | OpenAPI 3.0 JSON |
| --- | --- | --- |
| IP Geolocation API | [ip-location-api/openapi.yaml](https://github.com/IPGeolocation/openapi/blob/main/ip-location-api/openapi.yaml) | [ip-location-api/openapi.json](https://github.com/IPGeolocation/openapi/blob/main/ip-location-api/openapi.json) |
| IP Security API | [ip-security-api/openapi.yaml](https://github.com/IPGeolocation/openapi/blob/main/ip-security-api/openapi.yaml) | [ip-security-api/openapi.json](https://github.com/IPGeolocation/openapi/blob/main/ip-security-api/openapi.json) |
| ASN API | [asn-api/openapi.yaml](https://github.com/IPGeolocation/openapi/blob/main/asn-api/openapi.yaml) | [asn-api/openapi.json](https://github.com/IPGeolocation/openapi/blob/main/asn-api/openapi.json) |
| IP Abuse Contact API | [ip-abuse-contact-api/openapi.yaml](https://github.com/IPGeolocation/openapi/blob/main/ip-abuse-contact-api/openapi.yaml) | [ip-abuse-contact-api/openapi.json](https://github.com/IPGeolocation/openapi/blob/main/ip-abuse-contact-api/openapi.json) |
| Time Zone API | [timezone-api/openapi.yaml](https://github.com/IPGeolocation/openapi/blob/main/timezone-api/openapi.yaml) | [timezone-api/openapi.json](https://github.com/IPGeolocation/openapi/blob/main/timezone-api/openapi.json) |
| Astronomy API | [astronomy-api/openapi.yaml](https://github.com/IPGeolocation/openapi/blob/main/astronomy-api/openapi.yaml) | [astronomy-api/openapi.json](https://github.com/IPGeolocation/openapi/blob/main/astronomy-api/openapi.json) |
| User Agent API | [user-agent-api/openapi.yaml](https://github.com/IPGeolocation/openapi/blob/main/user-agent-api/openapi.yaml) | [user-agent-api/openapi.json](https://github.com/IPGeolocation/openapi/blob/main/user-agent-api/openapi.json) |

For every API in one file, use the combined [openapi.yaml](https://github.com/IPGeolocation/openapi/blob/main/openapi.yaml). The `openapi.json` at the root of that repository is a Postman collection, not an OpenAPI document.

Full documentation: [ipgeolocation.io/documentation.html](https://ipgeolocation.io/documentation.html)
